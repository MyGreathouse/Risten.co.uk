# risten.co.uk

Root domain hub for **Risten Global Ltd** — UK-focused digital products built to actually help.

Live at [risten.co.uk](https://risten.co.uk), linking out to the product family, starting with **Life in the UK Test** and **Wealth Builder Pro**, with more on the way.

## What this repo is

A single static `index.html` — no build step, no framework, no dependencies. This is the root domain only; each product lives in its own separate repo and its own Vercel project, deployed to its own subdomain (or, where applicable, its own standalone domain).

## Stack

Plain HTML/CSS. Deployed via Vercel, connected directly to this repo's `main` branch.

## Updating

Edit `index.html` directly and commit to `main` — Vercel redeploys automatically. No local build required.
